## 使用备忘
- **位图 vs 矢量**：企微/微信 BOT 头像要 PNG/JPG → 用 `originals/` 里的位图；需放大到海报/大屏 → 用根目录 `.svg` 矢量版。
- **尺寸选择**：512 通用；1024 大屏/海报；256/128 小图标。
- **配色核对**：朱红 #e63e2e / 机灰 #7a8a90 / 鎏金 #c9a227 / 玄黑底 #14110f。
- **合规自检**：无武侠角色造型、无"神雕侠侣"字样、红鸟主色未被去标识。

## 生产流程（可复用）
1. **出图**：用 `PROMPTS_shendiao_sijie.md` 的提示词（通用风格锚点 + 单角色提示词 + 负面词）在 ChatGPT Image 生成，1:1 方形。
2. **归档**：母版存入 `originals/<name>-ai-YYYY-MM-DD.<ext>`。
3. **派生**：Pillow 处理 —— 居中方形裁切 → 1024 母版 → **4× 超采样椭圆遮罩**打圆 → LANCZOS 缩放出 1024/512/256/128 + 方形 1024。
4. **核字**（带中文的图必须做）：人工放大核对中文字形是否正确，不对则用矢量覆字。
5. **总览**：2×2 拼版输出 `_overview.jpg` 供团队分发。

## ⚠️ AI 生成中文字的已知坑
- ChatGPT/DALL·E 类模型**写中文字普遍不可靠**：常见"字形好看但字不对"。实例：禾安母版盾内为**风格化单字（形似"黍"）**，并非「禾安」二字。
- **对策**：
  1. 提示词里明确要求"用抽象几何笔画代替、不要生成错别字"（已写入提示词包）；
  2. 出图后**必须人工核字**，不能只看"像不像中文"——本项目曾一度误判为"没出错"，后自行更正；
  3. 关键文字（品牌名/字标）改用**矢量叠加**（见 `hean-vector-fixed.svg`）或出图后覆字；
  4. 用户决定：禾安**沿用母版**（字当图形符号处理），`hean-vector-fixed.svg` 保留备用。

## 环境注意（本机特有）
- **Bash 工具链缺失**：PortableGit 的 `bash.exe` 报 `mkdir/cp/ls/dirname: command not found`，所有文件操作必须走 **PowerShell**（`New-Item`/`Copy-Item`/`Remove-Item`/`Get-ChildItem`）。
- **PowerShell 不回显 stdout**：执行成功但输出为空，需把结果 `Out-File` 到临时文件再 Read 回显，或用 Glob 二次确认落盘。
- 控制台中文路径显示为乱码（如 `绁為洉鍐滄満`）属编码显示问题，**不影响实际文件读写**。
