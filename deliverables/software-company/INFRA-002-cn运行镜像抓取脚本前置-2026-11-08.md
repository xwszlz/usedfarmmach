## 3. 实现（三步，additive-only）

### 3.1 `ali-oss` → dependencies
- `package.json`：从 devDependencies 移到 dependencies（`^6.23.0` 版本范围不变）；**tsx 保留在 devDependencies，绝对不移**。
- `package-lock.json`：`npm install --package-lock-only --ignore-scripts` 重算 ⇒ 根包归属调整 + 移除 ali-oss 及其 47 个传递依赖的 `dev: true`（共 48 处）；无版本漂移、无 resolved URL 变化。
- 实证：`npm ls --omit=dev --package-lock-only ali-oss` → `ali-oss@6.23.0`；`tsx` → `(empty)`。

### 3.2 builder 阶段预编译（新增一条 RUN）
在 `Dockerfile.cn` 的 `RUN npm run build` 之后纯追加：

```dockerfile
RUN mkdir -p /app/dist && \
    ./node_modules/.bin/esbuild scripts/fetch_subsidy_images.ts \
      --bundle --platform=node --format=cjs \
      --alias:@=./src \
      --external:@prisma/client \
      --external:proxy-agent \
      --outfile=/app/dist/fetch_subsidy_images.js
```

- 依据：builder 阶段 `npm ci` 全量（含 devDeps）⇒ esbuild 0.28.0 可用（tsx 传递依赖）；产物为单文件 CJS，runner 未声明 `type: module`。
- **alias 实证**：`--alias:@=./src`（cwd=/app）与「依赖 tsconfig.json 的 paths」两种方案产出 **byte-identical**（1,458,007 字节），最终采用 team-lead 推荐的 `--alias:@=./src`；产物中 `@/` 出现 0 次，`src/lib/db.ts` / `raw-mode.ts` / `image-review.ts` / `oss-upload.ts` 均内联。
- **ali-oss 不设 external**，全量内联（产物中 `ali-oss` 字符串 220 处、无 `require("ali-oss")`）—— 避免 runner 找不到运行时依赖。
- **`@prisma/client` external**：runner 的 `/app/node_modules/@prisma/client` 来自 standalone 产物；现有 `scripts/import-articles-to-cn.js` 同样用 `require('@prisma/client')` 且线上在跑，可类比。产物 `require("@prisma/client")` 从 `/app/scripts/` 向上解析到 `/app/node_modules` ✓。
- **额外 `--external:proxy-agent`（实证必要）**：`node_modules/urllib/lib/detect_proxy_agent.js:24` 有惰性 `require('proxy-agent')`，该包在 lockfile 中仅为 optional 声明、未安装，esbuild 静态分析报 `Could not resolve "proxy-agent"`。该 require 仅在 `args.enableProxy || process.env.URLLIB_ENABLE_PROXY` 且有 proxy 时触发；.cn 容器不设代理、OSS 直连，分支不触发。产物保留 1 处 `require("proxy-agent")`。

### 3.3 runner 只 COPY 编译后的 `.js`
在 `Dockerfile.cn` 既有脚本 COPY 组末尾纯追加一行：

```dockerfile
COPY --from=builder --chown=nextjs:nodejs /app/dist/fetch_subsidy_images.js ./scripts/fetch_subsidy_images.js
```

- 运行命令从 `npx tsx scripts/fetch_subsidy_images.ts` 改为 `node scripts/fetch_subsidy_images.js`，参数 `--seed-file` / `--limit 20` 不变。
- runner 保持不装 tsx、不带 `.ts` 源码；既有 stage / `npm ci --only=production` / nginx / 健康检查一行未删改。
- **未修改** `scripts/fetch_subsidy_images.ts`（零改动；`.ts` 源码不进 runner，容器内运维看不到其注释，运行命令以本工单/Dockerfile 注释为准）。
