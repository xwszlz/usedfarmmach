开放直连 + 两级分销裂变 · 顶级营销方案

神雕农机 usedfarmmach · 战略营销机制设计　|　2026-09-07
依据：实测核对 main 分支代码（Product / User / Invitation / Settlement / CreditLot 等模型）

核心一句话：把平台从「平台担保、双方隔离」切回「开放直连的二手农机集市」——卖家发布时留联系方式、买家直接看到；同时把已有的邀请码骨架升级成两级 CPS 分销，让每一个用户都成为推广员，把付费项目（AI 估值深度报告 / 会员 / 参展 / 拍卖）的大部分收入作为推广费分出去。

一、战略定位：为什么这么改

原来的模式目标模式
平台担保交易，买卖双方不见面（联系方式被会员等级挡住）开放直连集市：联系方式是交易刚需，放开后卖家更愿意发、买家转化更高
获客靠广告/自然流量，单点投放全民分销：每个注册用户带专属分享码，转发即获客，获客成本转为推广费
付费项目（估值/会员/参展）无裂变每个付费项目都挂分享链接 + 两级佣金，把 50%~60% 收入给推广人
推广骨架只有「注册送积分」（Invitation / invite_reward）升级为付费 CPS：订单级归因 + 现金/积分结算

二、机制一：联系方式全放开（让买卖双方直接见面）

2.1 现状（代码核实）

  • Product 模型无任何联系方式字段，只挂 sellerId → User。
  • 发布表单（seller/products/new）只有 7 必填 + 11 选填，不含微信/电话/邮箱。
  • User 仅有 email? / phone?（注册时填，多数人只留邮箱）。
  • "查看卖家联系方式"是会员权益（usageViewContact / 会员档 benefits），即"隔离"的实现点。

2.2 改动方案

  1. 发布表单增加「联系方式」区块（3 个字段，默认从卖家账号带出、可改）： 联系微信、联系电话、联系邮箱。标记"选填但强烈建议填——填了成交率翻倍"。
  2. 写入数据：在 Product 上加 contactName? / contactWechat? / contactPhone? / contactEmail? （按 listing 维度存，比只存 User 灵活，允许同一卖家不同机器留不同号）。
  3. 商品详情页直接展示：对所有已登录用户展示（去掉会员等级门槛），未登录引导注册后可见。
  4. 移除"避免双方见面"逻辑：原 usageViewContact 计数 / 会员专属查看，降级为"登录即可看"，保留字段但不再挡。

合规提醒：展示个人电话/微信属于个人信息公开，需在发布时加明确勾选「我已同意公开联系方式用于交易沟通」+ 隐私说明；海外站（.com）按 GDPR 还需"登录后才可见"且提供撤回入口。这是放开的前提，不能省。

三、机制二：两级 CPS 分销裂变（分享链接营销）

3.2 归因规则（行业通用）

  • 优先级：URL ?ref= > 落地页写入的 _ref Cookie（30 天）。
  • 归因窗口：30 天（用户点链接后 30 天内付费，归该推广人）。
  • 防自推：不能用自己的码推自己付费（RiskReview 已有 same_device / same_phone / multi_register_ip 规则可直接复用）。

3.3 奖励比例（提议，待你拍板）

原则：把"大部分的钱"给中间推广人。按平台净收口径提成：

3.5 结算与反作弊（复用现有骨架）

  • 数据表：新增 AffiliateConversion（订单级：ref / 付费类型 / 金额 / 一级 / 二级 / 状态）；复用 Settlement.commission 记平台佣金，CreditLot 记积分奖励。
  • 反作弊：下单时跑 RiskReview（同设备/同手机/同付费账户/同注册 IP）——命中则标记不放佣。
  • 提现：.com 走 Stripe / 转账；.cn 先发平台积分抵扣（见合规），待微信支付商户号 + 经纪资质齐备后再发现金。

四、合规红线与分站策略（必须看）

🔴 这是整个方案能不能落地的命门。依据既有合规约定：

  • .cn（已 ICP 备）：可做「信息发布 + 会员/AI 估值等增值费」；禁收交易服务费、禁资金托管、禁接微信/支付宝商户号（未配）。
  • .com（境外 / Vercel + Stripe）：可收增值费、可 CPS 现金分润、可二级分销。

七、待你拍板的关键参数

  1. 一级佣金比例：提议 50%（"大部分"）。可上调到 60%~70%，或按项目差异化（深度报告高、会员中）。
  2. .cn 是否接受"先积分后现金"：建议先积分（合规），你拍板是否要等资质齐了再发现金。
  3. 二级分销：提议 .com 开 10%、.cn 不开。是否要在 .com 也关掉二级？
  4. 先动哪一批：建议先 P0（开放联系方式 + 分享入口，低风险快速上线），再 P1。
