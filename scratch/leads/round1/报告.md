## 4. ✅ `备注` 落地链路已修通（本分支上一并交付）

**这是 U7-B 能否生效的前提**：`[同号·关联：…]` 写在 `备注` 列，若备注整列被丢，
标记就白打、外呼员照样重复拨打。故本次**先把这个缺陷修掉**，再加标记。

**缺陷**：`src/lib/raw-listing/import-leads.ts`（原 `:287`）落库时把 `notes` **整体覆盖**：

```ts
notes: `[import] ${source} by ${actorId}`,   // ← 不读 row.notes，写什么都会被丢
```

**修复后**（本分支已推）：

```ts
notes: [`[import] ${source} by ${actorId}`, (row.notes ?? "").toString().trim()]
  .filter((part) => part !== "")
  .join("\n"),
```

- 分隔符固定为 `"\n"`：确定性，每个标记各占一行便于 grep/回溯；
- **无 row.notes（undefined / null / `""` / 纯空白）时输出与改动前逐字相同**，只有 `[import] …` 一句；
- **零风险**：`notes` **不参与** `contentHash`（hash 只取 brand/model/year/location/price/phone/name），
  故不影响导入幂等，也不会让已入库行产生重复。

⇒ 至此 `[性质]`／`[机型组]`／`[补全]`／`[电话占位]`／`[品牌兜底]`／`[自家·禁外呼]`／`[同号·关联：…]` 
**全部能真正落库**，U7-B 的备注互标才成立。
