## 3. 分类依据（为什么要这么分）

`contentHash = md5(brandName|modelName|year|location|priceCny??priceRaw??""|sellerPhone|sellerName)`

- **不参与 hash**：`sellerEmail` / `sellerWechat` / `sellerWhatsapp` → 现有 PATCH 白名单支持，补了也不改 hash ⇒ **零幂等影响**，标「可直接补」。
- **参与 hash**：`brandName` / `modelName` / `year` / `location` / `priceCny` / `priceRaw` / `sellerPhone` / `sellerName` → 现有能力不支持（只有 GET+PATCH，无 PUT；PATCH 白名单仅那 3 个字段）⇒ 标「需 T04 扩展」。
- 🔴 **扩展时必须在同一事务里重算 `contentHash`**：只改 hash 字段不改 hash，下次重导会被当成新行，产生重复。
