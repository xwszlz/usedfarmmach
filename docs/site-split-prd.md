## 一、可行性快答（结论先行）

| # | 问题 | 结论 | 关键理由 |
|---|------|------|----------|
| 1 | 当前 `.com`（Vercel 境外托管）能否直接做 ICP 备案？ | **不能** | ICP 备案前置条件：接入服务商（IDC/云）及服务器须位于**境内**，并需提供境内服务器租赁合同 + 域名实名认证。Vercel 为境外托管，不满足"境内接入"。`.cn` 必须独立部署于境内云（阿里云/腾讯云等）并完成 ICP 备案后方可合规运营。 |
| 2 | 微信小程序能否做商户收付通（电商收付通担保交易）？ | **能，已具备条件** | 小程序已完成 ICP 备案 + 已开通微信支付商户号。微信「电商收付通」支持平台型商户：资金直进卖家子商户、平台不碰资金，不构成二清；询价/报价（非拍卖、一对一盲报）模式已确认合规。担保交易仅在小程序侧闭环，网站仅做信息发布 + 询价，不触碰资金。 |
| 3 | 境外用户增值服务用 Stripe 是否合适？ | **合适，但仅限 .com / 境外** | Stripe 不服务中国大陆 RMB 收单，仅支持境外信用卡/外币。境外买家/卖家在 `.com` 购买 AI 估值、市场情报等增值服务，用 Stripe 收外币合规顺畅；**不得**用于 `.cn` 境内 RMB 交易（境内应用微信收付通/微信支付）。 |

**一句话结论**：`.com` 维持境外 + Stripe 增值服务；`.cn` 独立境内部署 + 微信小程序收付通担保交易；两站数据隔离、合规边界清晰，战略可行。

## 二、简单 PRD

### 2.1 产品目标（.com 与 .cn 分述）

**`.com`（国际化站）**
- **PG-1** 为全球境外买家/卖家提供二手农机交易信息撮合与发布平台。
- **PG-2** 以 Stripe 收取增值服务费（AI 估值、市场情报等），构建境外可持续营收。
- **PG-3** 数据可出境，但**不主动服务境内用户**，避免触碰国内合规红线。

**`.cn`（国内站）**
- **PG-1** 专注中国二手农机（尤其国产）**流通规范化**，落实元氏县/流通协会座谈会方案。
- **PG-2** 数据**留境内、不出境**，规避数据出境违规。
- **PG-3** 以信息发布 + 询价为入口，交易担保闭环走微信小程序收付通；可收增值服务费（会员/AI 估值/情报）。

### 2.2 用户故事

| 角色 | 用户故事 |
|------|----------|
| 境外买家 | 作为境外买家，我希望在 `.com` 按国家/机型检索全球二手农机并查看 AI 估值，以便快速比价决策。 |
| 境外卖家 | 作为境外卖家，我希望在 `.com` 发布多语 listings 并购买情报增值包，以便触达更多买家、提升成交率。 |
| 国内农户/购机方 | 作为国内农户，我希望在 `.cn` 查看农机权属核验与车况信息卡，并向卖家发起询价，以便买得放心。 |
| 合作社/大宗采购 | 作为合作社，我希望在 `.cn` 批量查看价格指数与展会信息，并通过小程序完成担保交易，以便合规集采。 |
| 政府监管方（元氏县等） | 作为农业农村局监管人员，我希望在 `.cn` 看到交易备案、权属核验与流通数据看板，以便规范本地流通。 |
| 国产农机经销商 | 作为国产经销商，我希望在 `.cn` 发布车源、参与地头展/展会，并获取市场情报，以便拓展国内销路。 |

## 三、`.cn` 落实「元氏县 / 流通协会座谈会方案」功能清单

> 来源：中国二手农机流通协会座谈会 / 河北元氏县二手农机规范化流通公共服务平台论证方案。
> 对接方：元氏县县长谢槟择、副县长兰禾、农业农村局局长戴喜武。
> 说明：下表标注优先级，并标注**可复用现有 P1 用户体系能力**（额度引擎 QuotaGuard、super_admin 双层校验、国内双轨邮件路由 ConsoleProvider 降级、UsageLog、8 语）。

| 功能（方案原项） | 优先级 | 可复用 P1 能力 | 落地说明 |
|------------------|--------|---------------|----------|
| 信息发布展示 | P0 | 用户体系、8 语、ConsoleProvider 降级 | 基础展示；`.cn` 接入境内后即可上线（备案前仅信息，不涉资金） |
| 权属核验 / 车况信息卡 | P0 | super_admin 双层校验、用户体系 | 车况信息卡模板 + 权属材料上传核验流程 |
| 评估估值（含 AI 估值） | P0 | QuotaGuard、UsageLog、增值服务 | AI 估值走会员额度（`.cn`）/ Stripe（`.com`） |
| 会员与增值服务（AI 估值/情报） | P0 | QuotaGuard、UsageLog、双轨邮件 | 会员体系承载额度与计费，可收增值服务费 |
| 交易备案 / 合同 | P1 | 用户体系 | 仅备案登记；资金走小程序收付通，网站不碰钱 |
| 价格指数 / 市场情报 | P1 | QuotaGuard、UsageLog、增值服务 | 情报为增值服务，可收费，需 EDI 后更稳 |
| 地头展 / 展会 | P2 | 用户体系、信息发布 | 活动信息板块，引流至线下 |
| 政府监管数据看板 | P2 | 用户体系、UsageLog | 面向元氏县等监管方，展示流通/核验/备案数据 |

**复用结论**：P1 用户体系（QuotaGuard + super_admin + 双轨邮件 + UsageLog + 8 语）可**直接支撑**会员、AI 估值、情报、信息发布、权属核验鉴权；`.cn` 无需从零建设账户与额度体系，只需境内部署 + 备案 + 小程序联动。

## 四、两条线合规边界

### `.cn`（境内）
- **备案**：需 ICP 备案（1-3 月）→ EDI 许可证（3-6 月）；确认非拍卖模式（询价/报价合规）。
- **资金**：担保交易经**微信小程序收付通**（资金直进卖家子商户，平台不碰钱，不构成二清）；网站侧仅信息发布 + 询价。
- **数据**：数据**不出境**，境内存储与备份。
- **收费**：可收**增值服务费**（会员、AI 估值、情报等）；未备案期间**不得**收交易费/资金托管/接微信支付宝商户号（网站侧），但增值服务费可收。
- **红线**：未备案不得做资金托管 / 交易费；不得将数据传输出境。

### `.com`（境外）
- **收款**：Stripe **仅**用于增值服务费（AI 估值、情报），仅外币，不涉 RMB。
- **服务对象**：**不主动服务境内用户**（geo 提示 / 区域限制），避免触发境内合规与数据出境。
- **数据**：数据可出境，但**避免收集境内用户数据**；提供隐私政策与删除机制。
- **红线**：不得用 Stripe 收境内 RMB；不得向境内用户主动营销或留存其个人信息。
