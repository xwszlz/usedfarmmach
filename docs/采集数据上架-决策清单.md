## A. 阻塞 P0（不拍板无法开工）

**1. 无图商品是否展示？**（`RawListing.images` 恒为 `null`，805 行全空）
- 可选：**A** 允许无图上架（最快闭环；转化率/SEO 差）｜**B** 必须回源抓图后才上架（体验最好；有抓取成本 + 图片版权/防盗链风险）｜**C** 先无图上架、异步回源补图（平衡）
- 建议：**C**（P0 先按 A 打通闭环，P1 升级 C）｜影响：转换脚本 + 前台无图占位渲染（两端站）
- 请勾选：☐A  ☐B  ☐C

**2. 转换后 `Product.status` 取什么？**（前台仅读 `active`）
- 可选：**A** 一律 `draft`，人工确认后批量发布 `active`（安全；多一步人工）｜**B** 直接 `active`（最快；噪声直达前台）｜**C** 高置信子集自动 `active`、其余 `draft`（需置信评分，较重）
- 建议：**A**（守住前台质量）｜影响：转换脚本 + admin 发布动作（两端站）
- 请勾选：☐A  ☐B  ☐C

**3. 审核责任人是谁？**
- 可选：**A** 仅 `admin`/`super_admin`（权限收紧）｜**B** 含 `editor` 也可审（分担工作量）｜**C** 仅 `super_admin`（最严）
- 建议：**B**（复用现有 admin 鉴权角色集）｜影响：审核 API 角色校验 + 是否需操作审计留痕（两端站）
- 请勾选：☐A  ☐B  ☐C

**4. 是否回源抓图？**（决定第 1 题能否走 B/C）
- 可选：**A** 不回源，接受无图（零成本）｜**B** 回源抓主图 → 传 OSS（体验好；第三方 ToS/版权/防盗链待评估）｜**C** 仅国内源回源、国际源不回（折中）
- 建议：**C**（国际源版权风险高，先只做国内源）｜影响：转换脚本 + `oss-upload` 复用（`domestic_*` 落 `.cn`）
- 请勾选：☐A  ☐B  ☐C

## B. 影响转换/规则设计（尽早定）
